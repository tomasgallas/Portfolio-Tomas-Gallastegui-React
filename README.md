# Portfolio Web - Tomás Gallastegui

Portfolio personal desarrollado en React y Vite con soporte para dos idiomas (Español / Inglés) y un asistente de Inteligencia Artificial integrado con Groq Cloud.

## Características

- Soporte bilingüe en tiempo real (Español / Inglés).
- Asistente de IA interactivo para responder sobre proyectos y experiencia.
- Carrusel de proyectos interactivo con Swiper.
- Diseño responsive adaptado a celulares y computadoras.
- Botón para copiar correo al portapapeles y enlace a CV online.

## Tecnologías

- React 19
- Vite
- CSS3
- Swiper
- Groq Cloud API

## Instalación

1. Clonar el repositorio:
```bash
git clone https://github.com/tomasgallas/portfolio-react.git
cd portfolio-react
```

2. Instalar dependencias:
```bash
npm install
```

3. Crear archivo `.env` en la raíz:
```env
VITE_GROQ_API_KEY=tu_clave_de_groq_aqui
```

4. Ejecutar el proyecto:
```bash
npm run dev
```
